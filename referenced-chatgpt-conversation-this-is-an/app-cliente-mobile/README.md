# Arremate — protótipo mobile

Interface mobile premium inicial para os assinantes do sistema de leilões. É um protótipo navegável, com dados demonstrativos; ainda não está conectado ao capturador OCR, à API ou ao Supabase.

## Visualizar

Abra `index.html` no navegador do computador ou celular. Para simular uma tela de telefone no computador, use o modo responsivo das ferramentas do navegador.

## Telas implementadas

- Início com leilão ao vivo e próximos eventos.
- Detalhe do leilão ao vivo: vídeo autorizado, lote, preço, descrição e movimentação.
- Histórico de lotes.
- Lotes salvos.
- Perfil do assinante.
